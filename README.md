# Savoré

A static restaurant landing page based on the supplied design reference, built with Next.js App Router, TypeScript, Tailwind CSS, Lucide React, and Google Fonts through next/font.

## Development

```sh
npm install
npm run dev
```

Open http://127.0.0.1:3000.

## Validation

```sh
npm run lint
npm run typecheck
npm run build
```

The mobile navigation is interactive. Reservation and menu buttons are intentionally decorative, as specified in the static project brief. Home, About, and Gallery links scroll to existing page content. No backend or reservation service is connected.

Photographs are downloaded into public/images from Unsplash. Source photo IDs: hero `1519708227418-c8fd9a32b7a2`, restaurant `1517248135467-4c7edcad34c4`, chef `1577219491135-ce391730fb2c`, dessert `1578985545062-69928b1d9587`. These are practical alternatives to the reference photography.
